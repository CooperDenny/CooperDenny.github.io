Victorian Property Prices Dashboard

An interactive Power BI report on Victorian residential property sales. Compare median prices and year-on-year change by region, suburb and property type, and see every sale on a map.

  • Power BI
  • Power Query
  • DAX
Open dashboard full screen

At a glance

The question

How do property prices differ across Victoria’s regions and suburbs, and which way are they moving?

What I did

  • Cleaned a Kaggle dataset of Victorian property sales in Power Query: removed irrelevant rows, fixed data errors, and reshaped columns for geographic and time analysis.
  • Wrote DAX measures for median sale price and year-on-year change.
  • Built a map of sold properties with slicers for region, suburb and property attributes.

Outcome

A self-serve report where anyone can drill from the whole state down to a single suburb and see prices, recent sales and the trend in a few clicks.

The dashboard

On a phone? The report is easier to use full screen, rotated to landscape.

What you can do with it

  • Map: every sold property plotted across Victoria.
  • Filter by region, suburb and property attributes with slicers.
  • Compare prices, locations and key attributes in interactive tables.
  • Track median prices and year-on-year change with calculated measures.

Data and preparation

The source is a Kaggle dataset of Victorian property sales, with location, price, property type and sale date for each sale. Preparation was done entirely in Power BI:

  • Power Query: filtered out irrelevant entries, corrected data errors, and transformed columns to support geographic and time-based analysis.
  • DAX: calculated columns and measures for median prices and year-on-year trends.
